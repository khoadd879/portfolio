# Trần Khoa — Portfolio

Portfolio tiếng Việt dùng HTML, CSS và JavaScript thuần. Không cần cài dependency hoặc build. Thiết kế responsive với giới thiệu, ba dự án được ghim, GitHub và LinkedIn.

## Xem trên máy

Mở `index.html` bằng trình duyệt, hoặc chạy trong thư mục này:

```sh
python3 -m http.server 8000
```

Truy cập http://localhost:8000.

## Đưa lên GitHub Pages

1. Tạo repository **public** có tên `khoadd879.github.io` trên tài khoản `khoadd879`.
2. Chọn **Add file → Upload files**, tải các file `index.html`, `styles.css`, `script.js`, `favicon.svg` và `.nojekyll` vào thư mục gốc của repository, rồi commit. Có thể dùng Git để push thay cho upload.
3. Vào **Settings → Pages → Build and deployment**.
4. Chọn **Source: Deploy from a branch**, **Branch: main**, thư mục **/ (root)**, rồi **Save**. Nếu dùng tên nhánh khác, chọn nhánh chứa các file.
5. Chờ GitHub hoàn tất triển khai. Website sẽ có địa chỉ **https://khoadd879.github.io/**.

Nếu repository có tên `portfolio`, website sẽ là **https://khoadd879.github.io/portfolio/**. Các đường dẫn tài nguyên trong trang đều tương đối, hỗ trợ cả hai cách.

Hướng dẫn chính thức: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Chỉnh sửa

- **Nội dung, liên kết, dự án:** `index.html`.
- **Màu, font và bố cục:** `styles.css`; các màu chính ở `:root`.
- **Năm ở chân trang:** tự cập nhật bằng `script.js`.
- **Biểu tượng tab:** `favicon.svg`.

Font Be Vietnam Pro được tải từ Google Fonts; trang dùng font hệ thống khi không có mạng. Các hình dự án được vẽ bằng HTML/CSS, là minh họa khái niệm chứ không phải ảnh chụp ứng dụng.
